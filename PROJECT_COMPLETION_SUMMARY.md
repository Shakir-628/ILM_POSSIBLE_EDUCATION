## 🚀 How to Run

### 1. Marketing Website
```bash
cd marketing-website
npm install
npm start
# or
npm run dev    # with nodemon
```
Visit: `http://localhost:8080`

### 2. Backend Server
```bash
cd server
npm install
npm start
```
API: `http://localhost:5000/api`

### 3. Web Application
```bash
cd client
npm install
npm start
```
Web App: `http://localhost:3000`

### 4. Mobile Application
```bash
cd mobile-app
npm install --legacy-peer-deps
npm start
# Scan QR with Expo Go app
```
